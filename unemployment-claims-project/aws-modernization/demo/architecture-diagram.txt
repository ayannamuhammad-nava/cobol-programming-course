    =========

    +-------------------------------------------------------------------+
    |                                                                   |
    |  Identity:    Cognito User Pools (MFA for admins)                |

================================================================================
  COBOL (Before)                    -->   AWS (After)
  --------------------------------        --------------------------------
  UNEMPCLM.cbl batch loop          -->   Step Functions orchestrator
  GETCLAIM.cbl data operations     -->   6 Lambda microservices
  VSAM KSDS file                   -->   Aurora PostgreSQL (temporal)
  SYSIN 200-cmd batch limit        -->   SQS unlimited message queue
  PIC X(05) max 99,999             -->   INTEGER max 2,147,483,647
  REWRITE (overwrites data)        -->   INSERT new version (preserves history)
  OUTCLAIM.txt flat report         -->   QuickSight dashboards + PDF + Athena
  No authentication                -->   Cognito JWT + role-based access
  No audit trail                   -->   CloudTrail + audit log table
================================================================================
